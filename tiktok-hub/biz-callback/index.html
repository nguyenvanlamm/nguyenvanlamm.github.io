Đang quay về TikTok Hub…

TikTok API for Business chỉ chuyển hướng về địa chỉ https, nên trang này chuyển mã cấp quyền về TikTok Hub đang chạy trên máy của bạn. Trang không lưu và không gửi mã đi đâu khác.

English: returning to TikTok Hub on this computer. This page only forwards the authorization code to the locally running app; it stores nothing.

Bấm vào đây nếu trình duyệt không tự chuyển

Không mở được? Kiểm tra TikTok Hub đang chạy (./start.sh) và bạn đang dùng trình duyệt trên chính máy đó — hoặc đã mở SSH tunnel tới máy chủ.
